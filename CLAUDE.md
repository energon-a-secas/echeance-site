# CLAUDE.md: Echeance

Credential expiry tracker: a YAML inventory (metadata only, never secret values)
rendered as an urgency board, table, calendar and ICS export, plus renewal
tutorials published as llms.txt for agent sessions.

**Live:** echeance.neorgon.com · **Port:** 8875

## Run

```bash
make serve
```

Then open http://localhost:8875. It must be served over HTTP: the app is ES modules, and `file://` blocks them.

## Data

- `localStorage['echeance-yaml']`: the applied inventory document
- `localStorage['echeance-notified']`: reminder dedup marks
- `localStorage['echeance-prefs']`: board grouping choice
- `localStorage['echeance-remote-icons']`: opt-in remote favicon tier
- `data/`: sample inventory + tutorials (tutorials feed llms.txt)
- `assets/brands/`: vendored Simple Icons SVGs (CC0), see js/brand.js

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- No single JS file over ~500 lines. It currently holds.

## Gotchas

- **`inventory.local.yaml` is the owner's real inventory and is gitignored.** The repo
  is public; that file must never be committed. The app probes it with fetch on load
  (localStorage first, then the local file, then `data/sample.yaml`), so production
  logs one expected 404 for it on every fresh visit.
- **llms.txt is generated.** Edit `data/tutorials.yaml`, then `make llms`, and commit
  both. Editing llms.txt directly is lost on the next regeneration.
- **YAML dates parse with CORE_SCHEMA on purpose** (`js/yaml-io.js`). The default
  js-yaml schema turns `2026-05-28` into a JS Date and breaks round-trips. The
  validator also rejects rollover dates like `2026-13-45`, which the format regex
  alone would pass.
- **"Renewed today" rewrites the YAML document from parsed state**, so hand-written
  comments in the applied document do not survive it. The toast says so.
- **Severity treats `status: expired` with no date as expired**, not unknown; and
  `expires: never` is a distinct state from a missing `expires` (unknown is a risk,
  never is a decision).
- **The credential name is the button** in board cards and table rows. Do not put
  `role="button"`/`tabindex` back on the card or row; nested interactive elements
  was the one audit finding this replaced.
- **Brand icons are three-tier by design** (`js/brand.js`): vendored SVG, letter
  badge, then opt-in remote favicons (Google s2), default off because hotlinking
  discloses every service in a real inventory to a third party. Simple Icons has
  no AWS/Slack/OpenAI mark (trademark removals): those letter-badge locally.
- **ICS output excludes revoked/retired entries** and folds lines at 74 chars per
  RFC 5545; test changes with the Node one-liner in the repo history rather than
  eyeballing a download.

## Do not touch
